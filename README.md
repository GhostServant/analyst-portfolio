# Никита Зворыгин - Портфолио

Персональный сайт-портфолио стажера-системного аналитика.

## 🚀 О проекте

Современный одностраничный сайт-портфолио, созданный с использованием Astro и современных веб-технологий. Сайт демонстрирует навыки в области системного анализа, UML моделирования, BPMN процессов и frontend разработки.

## ✨ Особенности

- **Современный дизайн** с 3D анимациями и эффектами
- **Адаптивная верстка** для всех устройств
- **Интерактивные графики** навыков и компетенций
- **Анимации при скролле** для улучшения UX
- **Оптимизированная производительность** благодаря Astro

## 🛠️ Технологии

- **Astro** - современный фреймворк для статических сайтов
- **HTML/CSS/JavaScript** - базовая веб-разработка
- **CSS Grid & Flexbox** - современная верстка
- **CSS Animations** - плавные анимации
- **Responsive Design** - адаптивный дизайн

## 🚀 Запуск проекта

### Предварительные требования
- Node.js (версия 16 или выше)
- npm или yarn

### Установка
```bash
# Клонирование репозитория
git clone https://github.com/GhostServant/analyst-portfolio.git
cd analyst-portfolio

# Установка зависимостей
npm install
```

### Разработка
```bash
# Запуск dev сервера
npm run dev

# Сайт будет доступен по адресу http://localhost:4321
```

### Сборка для продакшена
```bash
# Сборка проекта
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🔧 Настройка

### Изменение контактной информации
Отредактируйте файл `src/components/Contact.astro`

### Добавление новых проектов
Обновите секцию проектов в `src/components/Projects.astro`

### Изменение навыков
Обновите `src/components/Skills.astro` и `src/components/Charts.astro`
